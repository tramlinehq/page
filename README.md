# Tramline Landing Page

Next.js static site for [tramline.app](https://www.tramline.app).

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Static output goes to `out/`.

## Blog

Add `.mdx` files to `src/content/blog/` with frontmatter:

```mdx
---
title: "Post Title"
date: "2024-01-15"
description: "A brief description"
---

Your content here.
```
