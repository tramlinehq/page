Writing CI server build workflows for mobile apps is cumbersome and time consuming. Every CI system has its own configuration format, its own way of defining jobs, storing files, and caching artifacts. Mobile apps in particular require complex toolchain configurations, especially when it comes to signed builds. If you're working with cross-platform frameworks like Flutter or React Native, the difficulties compound even further. That's why we built Macige — an open source generator that offers popular customizations for mobile app development CI workflows.

## Problem

Different CI systems use varying configuration methods for jobs, file storage, and caching. Mobile apps require complex toolchain configurations, especially for signed builds. When you add cross-platform frameworks like Flutter and React Native into the mix, the difficulties multiply. Setting up a proper CI pipeline from scratch for a mobile app can eat up days of developer time, and maintaining it across different platforms and CI providers is a constant source of friction.

## Solution

Macige stands for Mobile App CI workflow GEnerator. The idea is simple: you shouldn't need to create an account or sign up for anything just to get a working CI configuration for your mobile app. With Macige, you can generate workflows with your preferred settings and simply copy them into your projects. It's designed to get you up and running as quickly as possible, without the overhead of yet another service to manage.

## Current Features

Macige currently supports the following:

- GitHub Actions workflows for native Android, Flutter, and React Native projects
- Both debug and signed release builds, with guidance on secure secret storage
- Build file caching to accelerate compilation times across runs
- CI argument-based app versioning, so you can control version numbers directly from your workflow triggers

These features cover the most common needs for mobile app CI pipelines, and they're designed to work out of the box with minimal tweaking.

## Future

We have plans to expand Macige significantly. iOS workflow support is on the roadmap, along with support for additional CI providers like GitLab CI, Bitrise, and Codemagic. We're also exploring automated file writing for repositories, so that Macige can directly commit workflow files into your project rather than requiring you to copy and paste them.

## Technical

Macige is built with Yew, a Rust-based web framework that follows React and Elm-style patterns for building interactive web applications. Template handling is done with askama, and the entire application uses Rust compiled to WebAssembly for DOM interaction. This means the generator runs entirely in the browser with no server-side processing required.

Macige is open source under the MIT License. We welcome community contributions and would love to see pull requests, bug reports, and feature requests on GitHub. If you've been frustrated by the state of mobile CI configuration, give Macige a try and help us make it better for everyone.
