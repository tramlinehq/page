## Open source & public roadmap

Tramline released code under Apache 2.0, enabling self-hosting and community participation. A self-hosting guide is available on GitHub. Three rationales:

- Infrastructure software requires high reliability and longevity that open source provides
- Workflow software requires diverse perspectives for varied use cases
- Open source communities foster collaboration effectively

Public roadmap now on GitHub.

## Growth Plan: sign-ups now open

SaaS offering with priority support, integration maintenance, continuous updates. Onboarding assistance provided due to the integration-heavy nature of the product. Demo call available.

## Enterprise Plan: now available

For organizations with regulatory needs and access constraints. SLAs, release consulting, managed hosting.
